# 五子棋 · 联机对战部署说明

本程序支持三种联机方式：同网络(局域网)直连、公网服务器中转、frp 内网穿透。
游戏内点击 **联机对战** 即可弹出设置窗口，选择"创建房间(主机)"或"加入房间(客户端)"。
默认端口 `9876`，主机执黑先手，客户端执白。

---

## 一、同网络(局域网)直连

两台电脑连同一个 WiFi/路由器即可：

1. 主机端：点"联机对战" → 选"创建房间" → 记下对话框显示的 **本机 IP**(如 `192.168.1.10`)。
2. 客户端：点"联机对战" → 选"加入房间" → 填入主机的 IP → 确定。
3. 连上后双方轮流落子。

> 若连不上：检查 Windows 防火墙是否放行了 `Gomoku.exe` 的 9876 端口(首次运行会弹窗，选"允许")。

---

## 二、跨网络联机 —— frp 内网穿透(免费，推荐用于测试)

不同网络(比如一个在家、一个在学校)无法直连，需要一台有**公网 IP** 的服务器做中转。
[frp](https://github.com/fatedier/frp) 能把你本地的端口"穿透"到公网，对方连公网地址即可。

### 准备
- 一台有公网 IP 的服务器(阿里云/腾讯云最便宜的轻量服务器即可，学生机几元/月)。
- 下载 frp(服务端 `frps`、客户端 `frpc` 要版本一致)：https://github.com/fatedier/frp/releases

### 1) 公网服务器上运行 frps(服务端)
新建 `frps.ini`：
```ini
[common]
bind_port = 7000            # frp 通信端口
# 可选:dashboard 网页面板
dashboard_port = 7500
dashboard_user = admin
dashboard_pwd = 123456
```
启动：
```bash
./frps -c frps.ini
```
放行服务器安全组的 `7000`、`7500` 和下面用到的 `9876` 端口。

### 2) 主机端(创建房间的人)运行 frpc(客户端)
新建 `frpc.ini`：
```ini
[common]
server_addr = 你的服务器公网IP
server_port = 7000

[gomoku]
type = tcp
local_ip = 127.0.0.1
local_port = 9876          # 本地五子棋监听端口
remote_port = 9876         # 映射到服务器的公网端口
```
启动：
```bash
./frpc -c frpc.ini
```

### 3) 开始联机
- 主机端：游戏里"创建房间"(端口 9876)，此时 frp 已把它的 9876 穿透到服务器公网 9876。
- 客户端：游戏里"加入房间"，IP 填 **服务器公网 IP**，端口 `9876`，确定即连上。

> 原理：客户端 → 服务器公网IP:9876 → frps → frpc → 主机本地:9876。
> 游戏代码无需任何修改，frp 对程序完全透明。

## 三、跨网络联机 —— 公网服务器中转(正式用)

最稳定的方式：把"创建房间"的玩家换成云服务器本身。
但本项目采用 **主机即服务器** 架构(主机跑 QTcpServer)，最简单的正式部署是：
把程序部署在云服务器上作为主机，两个真人客户端都连服务器——

更常见的做法是直接用上面 frp 方案，或自行扩展一个"专用中转服务器"。
对五子棋这种回合制小游戏，frp 方案完全够用且零成本。

## 四、常见问题

| 现象 | 排查 |
|------|------|
| 一直"等待对手连接" | 防火墙/安全组没放行 9876；或 IP 填错 |
| 客户端"连接失败" | 主机没创建房间、IP/端口错、或 frp 未跑通 |
| 连上后对手落子不显示 | 一方点了"重新开始"会发 RESET 同步，正常 |
| 想换端口 | 创建/加入房间时改端口编辑框，双方保持一致 |

## 协议说明(给开发者)

网络层 `NetManager` 用行文本协议，`'\n'` 分隔：
- `MOVE 行 列\n` —— 落子
- `RESET\n` —— 重新开始

如需扩展(聊天、认输、计时)，在 `netmanager.cpp` 的 `processLine()` 增加新指令即可。
